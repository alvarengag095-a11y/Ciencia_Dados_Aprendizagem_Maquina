# Projeto 60 Mais — Data Science

## Metodologia

O projeto será desenvolvido com base na metodologia CRISP-DM (Cross-Industry Standard Process for Data Mining), que organiza o desenvolvimento de projetos de Ciência de Dados em seis etapas: compreensão do negócio, compreensão dos dados, preparação dos dados, modelagem, avaliação e implantação.

Referência: IBM. *Guia do IBM SPSS Modeler CRISP-DM*. Disponível em: https://www.ibm.com/docs/pt-br/SS3RA7_18.5.0/nl/pt/BR/pdf/ModelerCRISPDM.pdf.

## 1. Definição do negócio

### 1.1. Contextualização

O projeto 60 Mais tem como finalidade promover a inclusão digital de pessoas idosas, oferecendo ensino e auxílio no uso de tecnologias, como celulares, notebooks, aplicativos, sites e serviços disponíveis na internet.

A Ciência de Dados pode contribuir para compreender as principais dificuldades dos participantes, identificar as tecnologias que apresentam maior demanda por auxílio e analisar oportunidades de aprimoramento das atividades educacionais.

### 1.2. Problema de negócio

O projeto atende pessoas idosas com diferentes níveis de familiaridade com as tecnologias digitais. Nesse contexto, existe a necessidade de compreender suas principais dificuldades e identificar quais atividades de ensino podem ser aprimoradas para atender melhor às suas necessidades.

### 1.3. Pergunta de negócio

Quais são as principais dificuldades enfrentadas pelos participantes do projeto 60 Mais no uso de tecnologias digitais e como essas informações podem contribuir para melhorar as atividades de ensino e inclusão digital?

### 1.4. Objetivo geral

Analisar as principais dificuldades enfrentadas pelos participantes do projeto 60 Mais no uso de tecnologias digitais, utilizando técnicas de Ciência de Dados para identificar padrões e oportunidades de melhoria nas atividades de ensino e inclusão digital.

### 1.5. Objetivos específicos

- Identificar as principais dificuldades dos participantes no uso de tecnologias digitais.
- Analisar quais dispositivos, aplicativos e serviços apresentam maior demanda por auxílio.
- Investigar possíveis relações entre familiaridade digital e necessidade de suporte.
- Identificar padrões nas dificuldades relatadas.
- Gerar informações que contribuam para o planejamento das atividades educacionais.

### 1.6. Objetivos de Data Science

- Realizar análise exploratória dos dados dos participantes.
- Identificar e quantificar as dificuldades mais frequentes.
- Analisar a distribuição das necessidades de auxílio.
- Investigar relações entre as características dos participantes e suas dificuldades.
- Produzir visualizações e informações que apoiem a tomada de decisão.

### 1.7. Critérios de sucesso

O projeto será considerado satisfatório se conseguir identificar as principais dificuldades dos participantes, analisar as tecnologias que demandam maior auxílio e produzir informações úteis para o aprimoramento das atividades do projeto 60 Mais.

### 1.8. Recursos e limitações

Os recursos previstos incluem dados dos participantes, questionários ou registros de atividades, ferramentas de análise de dados e recursos computacionais.

As principais limitações estão relacionadas à disponibilidade, quantidade e qualidade dos dados, além da necessidade de preservar a privacidade dos participantes.

### 1.9. Benefícios esperados

Espera-se que os resultados contribuam para uma melhor compreensão das necessidades dos participantes, auxiliando no direcionamento das atividades de ensino e no fortalecimento das ações de inclusão digital promovidas pelo projeto 60 Mais.
